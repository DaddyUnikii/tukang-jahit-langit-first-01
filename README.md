# Tukang Jahit Langit

An original offline puzzle about mending a torn-paper night sky with golden thread. Sew bridges between numbered islands, rescue a growing flock of fireflies and bring every light to the little house. Cut bridges behind you to reuse limited thread. One strand holds one firefly; two hold three.

## Play
Open `game/index.html` in a current desktop Chrome (no build, install, internet or account required). If your browser restricts local files, run:

```sh
node server.mjs
```

Then open `http://127.0.0.1:8080`. The server binds only to loopback. All art is drawn by the game's Canvas2D renderer and all sound is generated by WebAudio after a user gesture. No external font, asset, CDN, telemetry or runtime AI.

## Controls
- **S / Sew:** click two pins or drag between them. Choose Single or Double thread.
- **Space:** let the fireflies walk; **G / Guide:** click a neighboring stitched island.
- **C / Cut:** click a bridge, refunding all its thread while the flock rests at an island.
- **1–8:** choose pins using the active tool. **U/Z:** undo. **R:** restart. **Esc:** back.
- Nightbook selects unlocked evenings; language toggles English/Indonesian; sound can be muted.

Complete all eight handcrafted evenings. Collect optional flowers and stay within the move target for three stars. A bridge too weak for the flock snaps; undo the crossing or restart to try a different route. There is no timer or penalty for experimenting.

## Test

```sh
node --test tests/*.test.mjs
```

The deterministic core tests use reachable player commands; level solutions are kept only in `tests/solutions.json`, never exposed as game cheat/autoplay controls. Read-only `skyDebug.snapshot()` lets local QA inspect state and contains no state setter.
